Kỹ Năng Cốt Lõi

Quản lý biến CSS tại `:root`, áp dụng Media Queries với `min-width`, kỹ thuật ẩn hiện thành phần `display: none`, hệ thống màu Dark/Light Mode và công thức tự co giãn Grid Auto-Fit.
