Responsive Typography Scale

Thiết lập hệ thống cỡ chữ h1, h2, h3, p sử dụng biến CSS. Media Query tại mốc 600px tự động giảm kích thước chữ khi màn hình nhỏ hơn để chống tràn chữ.

Heading 1 • var(--scale-h1)
Trần Lê Minh Huy: Kiến Tạo Giao Diện Thông Minh
Heading 2 • var(--scale-h2)
Nguyên Lý Thiết Kế Mobile First & Design System
Heading 3 • var(--scale-h3)
Tự Động Thích Ứng Trên Đa Nền Tảng Thiết Bị
Paragraph • var(--scale-p)
Đoạn văn bản thông thường được đặt kích thước tối thiểu 16px trên điện thoại di động giúp mắt đọc tự nhiên mà không cần phải dùng hai ngón tay zoom to. Khi kéo thay đổi chiều rộng trình duyệt qua mốc 600px, toàn bộ hệ thống chữ sẽ tự động điều chỉnh quy mô đồng nhất.
Mẹo kiểm tra: Hãy nhấn F12 chuyển chế độ Responsive của Chrome DevTools hoặc thu nhỏ cửa sổ trình duyệt xuống dưới 600px để trực tiếp quan sát các biến CSS cập nhật cỡ chữ mượt mà!
